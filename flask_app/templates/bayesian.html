How to Read This Model

What the model estimates

We fit a Bayesian hierarchical linear regression:

inflation(t) = α_country + β × conflict(t-1) + ε
  • α = country-specific baseline inflation
  • β = effect of lagged conflict on inflation
  • ε = unexplained noise

Key finding:
β = {{ "%.3f"|format(model.beta_mean) }} with 94% HDI [{{ "%.2f"|format(model.hdi_low) }}, {{ "%.2f"|format(model.hdi_high) }}]
The HDI includes zero, we cannot conclusively establish a positive or negative causal effect.

▶ Methodology: Bayesian Hierarchical Model

Model Specification

Hierarchical model:
  μ_α ~ Normal(3, 5)
  σ_α ~ HalfNormal(3)
  α_c ~ Normal(μ_α, σ_α)   # country-specific intercept
  β   ~ Normal(0, 2)         # shared effect across countries
  σ   ~ HalfNormal(5)
  inflation ~ Normal(α_c + β × conflict_z, σ)

Sampling: NUTS sampler · 4,000 draws × 4 chains = 16,000 posterior samples · 2,000 tuning steps · target_accept = 0.95 · All R-hat = 1.0
Software: PyMC v5, ArviZ, Python 3.10
